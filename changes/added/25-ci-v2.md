- The proofs can be checked several files at a time
  (`make -C proofs check J=4`), each file in its own EasyCrypt process,
  with its time and peak memory reported, and in the shards CI runs them in
  (`make -C proofs list-shards`, `make -C proofs check-shard SHARD=spec`).
  The imported crypto-specs theories are checked with their own load path
  only.
- Every CI check is listed in `ci/checks.toml` and runs on a
  workstation with `python3 ci/check.py run <check> <platform>`
  (`ci/README.md`).
